# Scripty-scripts
Collection of randoms scripts I have made on the way

## What is this repository?
Random Bash, Batch, python and other types of small scripts that someone might want to use but i cannot classify into a new repository because of their small size

## Usage
Find a script you'd like to use on the repository.

Open terminal and write the following command:
```
wget https://raw.githubusercontent.com/loudtrexx/Scripty-scripts/refs/heads/main/[SCRIPT_FILE]/
```
Replace [SCRIPT_FILE] with a file you'd actually like to use.

Or

Open a script file you'd like to download on github and press the download button.
